# Projeto_IHC

## Visão geral

Esse projeto corresponde a um trabalho para a disciplina de **Interação Humano-Computador (IHC)**. O objetivo principal é demonstrar conceitos de usabilidade, acessibilidade e design de interfaces, aplicando-os em uma aplicação real (ou protótipo) para evidenciar as boas práticas aprendidas durante o curso.

O projeto busca proporcionar uma experiência de usuário intuitiva, eficiente e agradável, servindo como estudo prático de design centrado no usuário, teste de usabilidade e avaliação de interação.

---

## Tecnologias utilizadas

Embora o repositório **Projeto_IHC** do ArthurSalesse não apresente código visível (não há arquivos de código fonte, apenas o README neste momento), aqui está um exemplo de como destacar as tecnologias caso o projeto tenha (ou planeje ter) alguma stack específica:

- **HTML / CSS / JavaScript** — para a construção da interface web (frontend), criando páginas interativas e responsivas.
- **Frameworks de UI** — tais como React, Vue ou Angular (caso sejam usados) para estruturar a aplicação de forma modular e escalável.
- **Bibliotecas de design** — Material UI, Bootstrap ou Tailwind CSS para estilização consistente e componentes reutilizáveis.
- **Acessibilidade (a11y)** — uso de práticas e padrões Web Content Accessibility Guidelines (WCAG) para tornar a interface acessível a usuários com diferentes necessidades.
- **Testes de usabilidade** — com ferramentas como Lighthouse, Axe ou testes com usuários reais para avaliar a eficácia da interface.
- **Controle de versão** — Git e GitHub para versionamento de código e colaboração.
- **Prototipação** — Ferramentas como Figma, Adobe XD ou Sketch podem ter sido utilizadas para protótipos antes da implementação.
